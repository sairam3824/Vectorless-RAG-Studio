# Northstar Company Handbook

## Remote Operations
Remote employees on primary on-call must acknowledge critical incidents within 15 minutes.
If no response is recorded after 30 minutes, the incident commander pages the backup engineer.

## Release Management
Production deployments move through the release pipeline after automated tests pass and an approver signs off.
Every release summary must include rollback steps and an owner for post-release monitoring.

## Customer Communications
Customer-facing postmortems are published within three business days when an outage exceeds 30 minutes.
Status page updates should begin within 10 minutes for any severity-one incident.
