# Structured Retrieval Brief

## Why Vectorless Retrieval
Vectorless retrieval is useful when teams want transparent scoring, easier local persistence, and deterministic evidence inspection.

## Page and Section Indexing
Page-level records preserve document layout while section-level records preserve author intent and heading structure.
Combining both makes citations easier to understand.

## Grounded Generation
The generation prompt should answer only from retrieved context and return a clear fallback sentence when the evidence is insufficient.
